# Published prioritization methods: feasibility on AIT (WP2 §6.3)

Written 14 September 2026. This matrix answers Reviewer 1 (points 5 and "Finally") and Reviewer 2 point 2: can a published alert-prioritization method be run faithfully on the AIT alert data used in the revision?

**AIT offers:**
- alert timestamps, detector (Wazuh, Suricata, AMiner), native rule or component identifiers and descriptions, host and IP strings, and Wazuh/Suricata native levels;
- scenario-level time-interval labels.

**AIT does not offer:**
- provenance graphs, asset or vulnerability inventories, analyst dispositions, investigation costs, or ATT&CK labels per alert.

The ATT&CK tactic of an AIT phase exists only through the author crosswalk.

Identity was verified against the publisher record or DOI. Method details were verified from the primary text where it was accessible; the right-hand "Verification" column says which.

## Conclusions for WP2

1. **None of the reviewed systems whose requirements could be verified can be run faithfully on AIT**; FuzMet and ROSCA remain undetermined. The verified systems require data AIT does not contain: provenance graphs, topology and vulnerability context, analyst feedback, or cost and adversary models. The revised paper must state this limitation and must not claim superiority over the state of the art.
2. **The WP2 families are the main answer to "compare with risk-based baselines"** (Reviewer 1 points 2, 4, 5; Reviewer 2 point 2), because they use the same information:
   - probability-risk proxy P;
   - cost-sensitive C with a declared C_FP grid;
   - tuned additive A and multiplicative M;
   - learned L1 and L2;
   - historical rule evidence R.
3. **DeepCASE is the only candidate with public code and partly compatible inputs.** Any use requires a pre-declared adaptation, with interval labels acting as simulated operator labels, and must be reported as an adaptation.
4. **Open items requiring author access to full texts:** FuzMet metric definitions and the ROSCA scoring rule. Until then both stay "undetermined" and are not approximated.
